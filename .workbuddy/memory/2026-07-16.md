1. grep 确认姓名在 MEAL_DATA 行（车辆/就餐数据可能同名多出现）
2. Python 正则 `var MEAL_DATA = (\{.*?\});\n` 提取 JSON（MEAL_DATA 是单行紧凑JSON，勿用[\s\S]贪婪）
3. 改学生 meals[餐次] 并同步 totals[餐次] 差值
